## Security properties verified by tests or configuration

- The application server listens on loopback only and rejects spoofed `Host` headers.
- Mutating HTTP routes require a per-process token.
- Browser responses use a restrictive Content Security Policy and other hardening headers.
- The configured OpenAI key is never returned by `/config`.
- Static-file traversal attempts are rejected.
- Transcript image payloads are type-checked and size-bounded; remote URLs are not fetched automatically.
- The updater is limited to packaged builds and requires confirmation before download and before restart/install.
- Desktop navigation permits the local application origin and routes external links through the operating system.

## Distribution status

The Windows x64 installer/portable package and universal macOS DMG/updater zip are the supported prebuilt shapes. Windows is not Authenticode-signed and macOS is not Developer ID-signed or notarized, so SmartScreen or Gatekeeper may warn on first launch. The project makes no code-signing claim. Users can verify file hashes and GitHub/Sigstore attestations independently from the release page.

## Residual risks and limits

- Agent transcript formats are implementation details of upstream products and may change.
- A loopback application still relies on the security of the local user account and browser/Electron runtime.
- Optional cloud narration intentionally sends the current narration source to OpenAI; it is not a fully offline feature.
 - Linux packaging remains contributor-only and is not claimed as an end-to-end supported release.

## FRAC7 heartbeat adapter extension

- The optional adapter accepts only the seven documented FRAC7 personas, the bounded status vocabulary, a valid timestamp, an optional 128-character trace ID, and a client-safe summary of at most 240 characters.
- It reads only `.fama/agent-heartbeats.jsonl` inside a user-selected project, attaches at EOF, and publishes only records appended while Fama is running.
- It deliberately drops client scope, ignores BUZZ credentials/messages/private memory/internal reasoning, and has no write or message-injection path.
- The viewer and native notifications label these records as BUZZ so provider attribution remains visible.
- Verification after the extension: 97/97 Node tests pass, including malformed-record rejection and selected-project live-only ingestion; modified JavaScript passed syntax checks and `git diff --check`.
