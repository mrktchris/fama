### Description (under 260 characters)

Fama turns the agent transcripts already on your computer into a live desktop
dashboard with optional spoken narration. Follow Claude Code and Codex in one
calm, local-first view—no account or telemetry required.

## First maker comment

> I built Fama because I kept losing the thread when several coding-agent tasks
> were running and I needed to switch windows. It turns the Claude Code and
> Codex transcripts already on your machine into a live dashboard, with optional
> narration when you are looking elsewhere.
>
> It is local-first: no Fama account, telemetry, or required API key. If you
> enable cloud voice, the narrated line (and its source text when summarization
> is on) is sent to OpenAI using your own key. One candid caveat: the Windows
> and macOS builds are currently unsigned, so please verify the checksum and
> provenance before opening them.
>
> I would love to know: what would make an ambient coding-agent companion useful
> enough for you to keep on a second monitor all day?

## Launch-day operating guide

- Post from a complete personal account and list every actual maker.
- Schedule only after links, gallery, video, and release notes are final.
- Be present for the full launch day and answer each question specifically.
- Invite existing testers to share honest experience; never coordinate votes,
  comments, or generic “congrats” replies.
- Capture repeated questions, installation failures, and requested integrations
  as GitHub issues while preserving private security reports.
- Publish a short public recap afterward: what users tried, what surprised you,
  and what will ship next.

## Do not claim

- That the Windows binary is Authenticode-signed.
- That the macOS app is Developer ID-signed or notarized.
- That cloud voice keeps all transcript content local.
- Compatibility or adoption claims that have not been tested with real users.
