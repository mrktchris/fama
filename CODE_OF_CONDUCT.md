# Code of conduct

Short version: be respectful, assume good faith, keep it about the code.

- Disagree about approach as much as you want, that's normal for a project like this. Don't make it personal.
- No harassment, insults, or discrimination of any kind, here or in any linked discussion.
- Maintainer decisions on scope/direction are final, but the reasoning behind them is always fair to ask about.

Reports of a violation, or anything that doesn't feel right, go to the maintainer via GitHub (open an issue if it's general, or a private security advisory if it involves sensitive detail, see `SECURITY.md`). Reports are handled privately and taken seriously.
